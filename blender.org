**To add custom properties to an object in blender using the
Python CLI

#+BEGIN_SRC python
>>> import bpy
>>> obj = bpy.content.object
Traceback (most recent call last):
  File "<blender_console>", line 1, in <module>
AttributeError: module 'bpy' has no attribute 'content'

>>> obj = bpy.context.object
>>> print(obj.keys())
<IDPropertyGroupViewKeys "user_properties">

>>> print(dict(obj.items()))
{'prop': 'prop_'}

>>> print(dict(obj.items()))
{'prop': 'prop_', 'prop1': '1.0'}

>>> obj["prop_asset"] = "tree_pine_01.glb"
>>> print(dict(obj.items()))
{'prop_asset': 'tree_pine_01.glb'}
#+END_SRC
