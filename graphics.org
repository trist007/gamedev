** Projection

Perspective mode - use Z axis as things get closer to camera they get bigger as shown below
Orthographic mode - all vertices are same size, no depth do not divide by point.z
#+BEGIN_SRC C
vec2_t
project(vec3_t point)
{
  vec2_t projected_point = {
  // ! NOTE: trist007: this is known as perspective divide
  // ! we divide by Z to give the illusion of depth
  // ! without this we have an orthographic projection instead
  // ! of a perspective projection
  .x = (fov_factor * point.x) / point.z,
  .y = (fov_factor * point.y) / point.z,
  };

  return(projected_point);

}
#+END_SRC
