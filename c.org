** restrict
(C99) is a pointer qualifier that makes a promise to the compiler: for the lifetime of that pointer, the object it points to is accessed only through that pointer (or pointers derived from it). No other pointer will alias that memory.

That promise lets the compiler optimize more aggressively, since it doesn't have to assume a write through one pointer might change what another pointer sees.

#+begin_src C
void add(int *a, int *b, int *c, int n) {
    for (int i = 0; i < n; i++)
        a[i] = b[i] + c[i];
}
#+end_src

Without restrict, the compiler must assume a might overlap b or c. Writing a[i] could change a later b[i+1], so it can't safely vectorize or reorder loads and stores.

#+begin_src C
void add(int *restrict a, const int *restrict b, const int *restrict c, int n) {
    for (int i = 0; i < n; i++)
        a[i] = b[i] + c[i];
}
#+end_src

Now the compiler knows the three arrays don't overlap, so it can keep values in registers, unroll, and use SIMD.

The catch: you're making a promise, not the compiler

If you violate it, the behavior is undefined:

#+begin_src C
int buf[10];
add(buf, buf, buf + 1, 9);   // UB: a and b/c overlap
#+end_src

The compiler won't warn you, and the code may silently produce wrong results at -O2.

Real-world examples
memcpy uses restrict on both pointers (source and destination must not overlap), while memmove does not, which is exactly why memmove handles overlap and memcpy doesn't.
strcpy, sprintf, and fread and friends also use it in their prototypes.
Notes
It only matters when the restricted object is modified. If everything is only read, aliasing is harmless anyway.
Using const alongside it on read-only inputs documents intent well.
It's a hint with no effect on correctness when used properly, so adding it never changes behavior in a valid program.
C++ has no standard restrict, but most compilers offer __restrict / __restrict__ as an extension.

Rule of thumb: use it on function parameters in hot loops where you know the buffers are distinct, and nowhere else.

#+BEGIN_SRC python
#!/usr/bin/env python3
"""
Generate compile_commands.json from a Windows cmd.exe build log containing
literal `cl ...` invocations (MSVC). compiledb/bashlex can't handle Windows
paths or recognize `cl` as a compiler, so this parses the log directly.

Some of your targets (game, game2, main) compile+link in ONE cl invocation
(no /c flag, with a trailing /link section and multiple source files at
once). That raw command line isn't a valid standalone COMPILE job -- clangd
needs one compile-only command per file. This script synthesizes a clean
compile-only command for each file: it strips everything from /link onward,
drops link-output flags (/LD, /Fe:, etc.), removes sibling source files, and
ensures /c is present.

Usage:
    python gen_compile_commands.py build_log.txt compile_commands.json <directory>

<directory> should be the working directory the cl.exe calls were actually
run from (e.g. C:\\dev\\wing\\wing\\build, since build.bat does `pushd ..\\build`
before invoking cl).
"""
import sys
import json
import re

SOURCE_EXTS = ('.c', '.cpp', '.cc', '.cxx')


def tokenize(command_line):
    """Whitespace tokenizer that keeps double-quoted tokens intact."""
    return re.findall(r'"[^"]*"|\S+', command_line)


def find_source_files(command_line):
    """Pull out source file tokens (.c/.cpp/.cc/.cxx) from a cl command line."""
    tokens = tokenize(command_line)
    sources = []
    for tok in tokens:
        stripped_tok = tok.strip('"')
        if stripped_tok.lower().endswith(SOURCE_EXTS):
            sources.append(stripped_tok)
    return sources


def build_clean_command(command_line, target_file):
    """
    Synthesize a clean COMPILE-ONLY command for `target_file` from a raw
    cl command line that may compile+link several files in one shot.
    """
    tokens = tokenize(command_line)

    # Truncate everything from /link (or /LINK) onward.
    link_idx = None
    for i, tok in enumerate(tokens):
        if tok.strip('"').lower() == '/link':
            link_idx = i
            break
    if link_idx is not None:
        tokens = tokens[:link_idx]

    # Drop link-output-only flags irrelevant to a compile-only job.
    drop_prefixes = ('/ld', '/fe:', '/fe', '/out:', '/implib:', '/pdb:')
    tokens = [t for t in tokens
              if not any(t.strip('"').lower().startswith(p) for p in drop_prefixes)]

    # Drop all source-file tokens except index 0 (the compiler name itself,
    # which never matches a source extension) -- we'll append target_file.
    out = []
    for i, tok in enumerate(tokens):
        stripped = tok.strip('"')
        if i > 0 and stripped.lower().endswith(SOURCE_EXTS):
            continue
        out.append(tok)
    tokens = out

    # Ensure /c (compile-only) is present.
    if not any(t.strip('"').lower() == '/c' for t in tokens):
        tokens.insert(1, '/c')

    tokens.append(target_file)
    return ' '.join(tokens)


def main():
    if len(sys.argv) != 4:
        print("Usage: gen_compile_commands.py <build_log.txt> <compile_commands.json> <directory>")
        sys.exit(1)

    log_path, out_path, directory = sys.argv[1], sys.argv[2], sys.argv[3]

    entries = []
    seen_files = set()

    with open(log_path, 'r', encoding='utf-8', errors='replace') as f:
        for raw_line in f:
            stripped = raw_line.rstrip('\n').strip()
            if not stripped.lower().startswith('cl'):
                continue

            command_line = stripped
            sources = find_source_files(command_line)
            if not sources:
                continue

            # Was this originally a compile-only (/c) invocation of a
            # SINGLE file? Then the raw command is already fine as-is.
            tokens = tokenize(command_line)
            has_c = any(t.strip('"').lower() == '/c' for t in tokens)
            single_file = len(sources) == 1

            for src in sources:
                if has_c and single_file:
                    cmd = command_line
                else:
                    cmd = build_clean_command(command_line, src)

                key = src.lower()
                entry = {"directory": directory, "command": cmd, "file": src}
                entries = [e for e in entries if e["file"].lower() != key]
                entries.append(entry)
                seen_files.add(key)

    with open(out_path, 'w', encoding='utf-8') as f:
        json.dump(entries, f, indent=2)

    print(f"Wrote {len(entries)} entries to {out_path}")
    print(f"Source files found: {sorted(seen_files)}")


if __name__ == '__main__':
    main()
#+END_SRC

** Carmack advice

If a function is only called from a single place, consider inlining it.

If a function is called from multiple places, see if it is possible to arrange for the work to be done in a single place, perhaps with flags, and inline that.

If there are multiple versions of a function, consider making a single function with more, possibly defaulted, parameters.

If the work is close to purely functional, with few references to global state, try to make it completely functional.

Try to use const on both parameters and functions when the function really must be used in multiple places.

Minimize control flow complexity and “area under ifs”, favoring consistent execution paths and times over “optimally” avoiding unnecessary work.
